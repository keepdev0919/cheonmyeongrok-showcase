## 무엇을 하나요

- 생년월일과 태어난 시간을 넣으면 사주팔자를 계산하고, **AI가 내 사주를 읽어 주듯 풀어서** 설명해요.
- 결과와 어울리는 **수호신 부적**을 디지털 굿즈로 받을 수 있어요.
- **회원가입이 필요 없어요.** 결과는 개인 링크로 언제든 다시 열어 볼 수 있어요.
